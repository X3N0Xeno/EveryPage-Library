# Everyday Library

**Everything Humanity Has Written, Open to Everyone.**

Everyday Library is a federated digital library built with **Blazor WebAssembly (.NET 8)**, **Tailwind CSS**, and **Supabase**. It unifies community-contributed `.pdf` editions with open-access books aggregated in real time from **Project Gutenberg (Gutendex)** and **Open Library / Internet Archive**.

## Key Features
- **Federated Web Catalog:** Searches community uploads alongside Project Gutenberg and Open Library across Philosophy, History, Science, Fiction, Literature, Technology, and Biography.
- **Direct Middleman Downloads:** Delivers `.pdf`, `.epub`, and `.txt` files directly to the user's browser while automatically indexing downloaded works and tracking download counts in Supabase.
- **Inline Document & Archive Reader:** Read community PDFs and Internet Archive books directly inside the browser alongside a reader notes thread.
- **PDF-Only Community Shelf:** Signed-in contributors upload original works or rare, hard-to-find editions strictly as `.pdf` files with bibliographic metadata and optional cover art.
- **Moderation & Audit Log:** Auditors can edit bibliographic metadata, soft-delete or restore catalog items, and inspect the append-only audit log.
